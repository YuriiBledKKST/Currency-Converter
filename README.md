# Currency Converter

**Автор:** Аникеев Даниил

## Описание

GUI приложение для конвертации валют с использованием внешнего API. Позволяет конвертировать суммы между различными валютами, сохраняет историю конвертаций и поддерживает актуальные курсы валют.

### Возможности:
- Конвертация между любыми валютами
- Автоматическое обновление курсов из API
- Сохранение истории конвертаций в JSON
- Просмотр истории в таблице
- Очистка истории
- Проверка корректности ввода

## Как получить API-ключ

1. Перейдите на сайт [ExchangeRate-API](https://app.exchangerate-api.com/sign-up)
2. Зарегистрируйтесь (можно через GitHub, Google или email)
3. После регистрации вы получите бесплатный API-ключ
4. Бесплатный тариф включает 1500 запросов в месяц
5. Ключ автоматически используется в приложении (не требует ввода)
